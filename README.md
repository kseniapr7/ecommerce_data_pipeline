# E-commerce Analytics Pipeline (Python + PostgreSQL)

## О проекте
Сквозной ETL-пайплайн для сбора, очистки и аналитики данных интернет-магазина. 
Проект эмулирует работу Data Engineer: от генерации «грязных» данных из CRM до построения аналитического хранилища (DWH) по схеме «Звезда».

## Стек технологий
- **Python** (стандартная библиотека `csv`, `random`, `datetime`)
- **PostgreSQL** (DWH, схема «Звезда»)
- **psycopg2** (взаимодействие Python с БД)
- **Git** (версионирование)

## Архитектура пайплайна
1. **Extract (Генерация):** Скрипт `generate_data.py` создает CSV-файл с 1000 записей, намеренно добавляя «мусор» (пропуски, дубликаты, отрицательные цены).
2. **Transform (Очистка):** Скрипт `etl.py` очищает данные от мусора (осталось 819 чистых записей) и приводит типы данных к нужным.
3. **Load (Загрузка):** Данные распределяются по 4 таблицам в PostgreSQL (схема «Звезда»).
4. **Analytics (Аналитика):** SQL-запросы (`sql/analytics.sql`) считают выручку, топ-товары и лучших клиентов.

## Схема данных (Star Schema)
- `fact_sales` (таблица фактов) — 819 записей.
- `dim_products` (справочник товаров) — 20 записей.
- `dim_customers` (справочник клиентов).
- `dim_locations` (справочник городов) — 6 записей.

## Как запустить проект
1. Клонировать репозиторий.
2. Установить зависимости: `pip install -r requirements.txt`
3. Запустить генерацию данных: `python generate_data.py`
4. Создать базу данных и таблицы в PostgreSQL (SQL-скрипты находятся в папке `sql/schema.sql`)*.
5. Запустить ETL: `python etl.py`
6. Открыть `sql/analytics.sql` и выполнить запросы в DBeaver.
