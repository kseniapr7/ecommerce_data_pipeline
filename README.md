# E-commerce Analytics Pipeline

## О проекте
ETL-пайплайн для сбора, очистки и аналитики данных интернет-магазина. 
Проект эмулирует работу инжинера данных: от генерации не очищенных данных из CRM до построения хранилища.

## Стек технологий
- **Python** (`csv`, `random`, `datetime`)
- **PostgreSQL** (DWH, схема Звезда)
- **psycopg2** (взаимодействие Python с БД)
- **Git**

## Архитектура
1. **Extract (Генерация):** Скрипт `generate_data.py` создает CSV-файл с 1000 записей, добавляя пропуски, дубликаты, отрицательные цены.
2. **Transform (Очистка):** Скрипт `etl.py` очищает данные от мусора и приводит типы данных к нужным.
3. **Load (Загрузка):** Данные распределяются по таблицам в PostgreSQL.
4. **Analytics (Аналитика):** SQL-запросы (`sql/analytics.sql`) считают выручку, топ-товары и лучших клиентов.

## Схема данных
- `fact_sales` (таблица фактов)
- `dim_products` (справочник товаров)
- `dim_customers` (справочник клиентов)
- `dim_locations` (справочник городов)

## Как запустить проект
1. Клонировать репозиторий.
2. Установить зависимости: `pip install -r requirements.txt`
3. Запустить генерацию данных: `python generate_data.py`
4. Создать базу данных и таблицы в PostgreSQL (SQL-скрипты находятся в папке `sql/schema.sql`)*.
5. Запустить ETL: `python etl.py`
6. Открыть `sql/analytics.sql` и выполнить запросы в DBeaver.
